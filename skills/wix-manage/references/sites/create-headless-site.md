# Create Headless Site

A Wix Headless site is a site in the user's Wix account whose frontend is files
uploaded to Wix hosting and served at a `*.wix-site-host.com` URL, with the Wix
business backend (stores, bookings, forms, a CMS) behind it through APIs.
Creating it, uploading its files, changing it later and connecting a backend are
one flow: [Upload a Website or HTML Files](upload-static-site.md).
