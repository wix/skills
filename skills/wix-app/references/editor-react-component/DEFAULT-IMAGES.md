# Default Images

Use this reference to choose Wix-hosted defaults for `Image` props and item
fields. `COMPONENT-CONTRACT.md` owns the `Image` default shape.

Choose how many items the design needs first; never reduce the count to fit
the pool. Give every image slot a default; never leave one empty. Fill slots
in order:

1. Rows whose tags match the component's purpose.
2. When those run out, or none match, the `general` rows not used yet:
   abstract 1–5, then views 25–27.
3. When those run out too, repeat the images already used, in the same order.

Build `url` as `https://static.wixstatic.com/media/<fileName>`, set `uri` to
the `fileName`, and set `alt` from the description.
