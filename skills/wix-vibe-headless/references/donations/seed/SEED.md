# Donations setup

When the user asks for campaign setup, use the owner-authorized
[Create and Update Donation Campaigns](../../../../wix-manage/references/donations/create-and-update-donation-campaigns.md)
recipe. If it is not installed, read
`https://www.wix.com/skills/wix-manage/references/donations/create-and-update-donation-campaigns.md`.
This vertical has no second seed implementation. Confirm the site and changes, read first, preserve
existing campaigns, and never run owner operations using the browser's visitor credentials.

For a frontend-only request, do not seed at all. Report missing campaign/payment setup rather than
creating mock causes, fundraising figures or a replacement site.
