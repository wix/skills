# Set up Donations

Read [Create and Update Donation Campaigns](../../../wix-manage/references/donations/create-and-update-donation-campaigns.md)
and execute its read-before-write flow with this project's owner-authorized credentials and site ID.
If the sibling skill is not installed, read
`https://www.wix.com/skills/wix-manage/references/donations/create-and-update-donation-campaigns.md`.

Reuse the supplied site's campaigns. Only create/edit the causes and settings the user approved;
do not manufacture a goal, deadline or impact claim. Keep any created campaign IDs only for setup
verification/media attachment; the frontend discovers campaigns live. The donation form and checkout
are [How to Code Donations](how-to-code-donations.md), not this setup operation.
